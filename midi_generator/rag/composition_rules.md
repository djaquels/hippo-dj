# Composition Rules

## 1. Phrase architecture

Prefer 4-bar phrases inside 8-bar sections.

Typical structure:

- Bars 1–2: motif statement
- Bars 3–4: motif repetition
- Bars 5–6: variation or response
- Bars 7–8: tension and resolution

Do not make every bar completely different.

## 2. Motif rule

Every important melodic instrument must have a recognizable motif.

A motif should contain:

- a recognizable rhythm
- a recognizable pitch contour
- 3–8 important note events
- at least one repeated rhythmic or pitch idea

Example:

`A4 A4 A4 C5 B4 A4`

Do not automatically simplify this to:

`A4 C5 B4 A4`

Repeated notes are intentional musical information.

## 3. Repetition

Use controlled repetition.

Preferred progression:

`A → A → A' → B`

where `A'` changes only one or two properties.

Possible changes:

- final note
- octave
- one passing note
- rhythm of the ending
- velocity
- anticipation
- register

Avoid:

`A → B → C → D`

when the phrases have no relationship.

## 4. Rests and breathing

Silence is part of the melody.

Use rests:

- after important motifs
- before phrase responses
- before transitions
- before climactic notes
- at the end of phrases

Do not fill every beat with notes.

A lead should frequently have empty rhythmic space.

## 5. Note hierarchy

Not every note has equal importance.

Use:

- structural notes: strong chord/key tones
- passing notes: connect structural notes
- approach notes: create tension immediately before a target
- pickup notes: lead into the next phrase
- climax notes: highest emotional points
- resolution notes: return to stable tones

Structural and climax notes should generally receive stronger velocity than decorative notes.

## 6. Melodic contour

Prefer meaningful shapes:

- rise → fall
- fall → rise
- arch
- question → answer
- repeated note → leap → resolution

Avoid continuously ascending or descending scales.

## 7. Rhythm

The motif rhythm is as important as its pitches.

Use a small rhythmic vocabulary and repeat it.

Useful rhythmic devices:

- offbeat entrances
- syncopation
- short-long combinations
- pickups
- held notes followed by short notes
- occasional repeated eighth/sixteenth-note cells

Do not make every note the same duration.

i.e

```
0.25–0.5 = ornaments / fast movement
0.5–1   = normal melodic notes
1.5–2   = expressive sustained notes
3–4     = phrase endings / held tones
```
## 8. Tension and release

Build tension through:

- anticipation
- non-chord tones
- upward movement
- longer held tension notes
- increased rhythmic activity
- higher register

Release through:

- chord tones
- descending movement
- longer final notes
- lower register
- rhythmic simplification
- short rests

## 9. Velocity

Avoid constant velocity.

Use approximate roles:

- background: 55–80
- normal melody: 75–105
- motif accent: 90–115
- climax: 100–120
- passing/decorative notes: 60–90

Velocity should create phrasing, not random variation.
