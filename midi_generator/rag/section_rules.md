# Section Rules

## Intro

Goal: establish groove and emotional color.

Typical ingredients:

- kick
- percussion
- pad/chords
- small guitar texture
- partial motif

Avoid presenting the full lead immediately.

## Verse / A Section

Goal: establish the main motif.

- introduce motif A
- repeat it
- leave space
- keep instrumentation controlled

## Build / B Section

Goal: create expectation.

- introduce variation A'
- increase rhythmic activity
- raise register slightly
- add anticipation
- increase drum density gradually

## Drop / Main Section

Goal: strongest recognizable identity.

- full groove
- complete lead motif
- country guitar response
- bass foundation
- strongest hook

Do not simply make every instrument louder. Increase musical density selectively.

## Breakdown

Goal: emotional contrast.

- remove or reduce kick
- expose harmony
- use sparse lead/guitar
- longer notes
- larger rests

## Final Drop

Goal: emotional payoff.

- return to main motif
- use highest-energy variation
- add octave/register reinforcement selectively
- use strongest climax

## Outro

Goal: resolution.

- remove layers
- simplify rhythm
- restate a shortened motif
- finish on a stable harmonic target
